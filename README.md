# Izla & Gabriel Hochzeit Website

## Starten

Im Projektordner im Terminal:

```bash
npm install
npm run dev
```

Dann im Browser öffnen:

```bash
http://localhost:5173
```

Stoppen:

```bash
Ctrl + C
```

## Build

Finale Version erzeugen:

```bash
npm run build
```

Gabriel: einfach nicht in `node_modules` rumspielen.
